# Security - portfolio

Public static site on GitHub Pages. Everything committed here is public.

- No server, no authentication, and no secrets are needed at runtime.
- A gitleaks pre-commit hook (`.githooks/pre-commit`) blocks commits that contain secrets.
- Personal details on the site are published on purpose; keep private contact details out of the repo.
- Detailed review notes are kept by the owner outside this repository.

## Reporting

Report concerns to the repository owner through their GitHub profile.
