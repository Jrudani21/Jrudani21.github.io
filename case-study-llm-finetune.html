Did my fine-tune work? Building an eval that can say no

I fine-tuned a small model on statistics questions. Before claiming it helped, I built a held-out test with an exact paired significance test and a separate LLM judge. The harness is done and tested. The honest result so far is no significant difference, and this page explains why that is still worth showing.

First, what this is not

It is not evidence that the fine-tune works. The tuned model is not on the machine I ran this from, so both columns below are two base models: qwen3-8b in the "base" column and qwen3.5-9b in the "tuned" column. I used them to test the harness itself. The real comparison is still to run.

The project

A pipeline that fine-tunes Qwen2.5 on applied statistics (Poisson and negative binomial regression, SARIMA, hypothesis tests, fraud modelling) using QLoRA on an 8 GB RTX 4060. It generates 240 training pairs locally, reviews them with an automated gate, trains and exports to Ollama. What it lacked was any measurement of whether the tuned model beats the base.

The harness

  1. Held-out questions the model never trained on, each with accepted keywords.
  2. Exact McNemar test on paired pass/fail, written with math.comb, no stats library.
  3. A separate judge model (gpt-oss-20b) that grades each answer 1 to 5 against a reference answer, then a paired sign test.
  4. One model loaded at a time, because alternating models on 8 GB of VRAM crashed the server.
  5. Unit tests for keyword hit and miss, a known McNemar value, the judge-reply parser and the question file.

The lesson. A harness that reports a number is not a harness that works. The 5% looked like a finding until I read the answers.

Results

question setkeyword passjudge mean (1 to 5)
Easy, n = 3097% vs 100%, McNemar p = 1.05.0 vs 5.0, all 30 tied
Hard, n = 1989% vs 84%, McNemar p = 1.04.05 vs 4.47, sign test p = 0.69 (2 / 4 / 13 ties)
  • The easy set could not tell the models apart, so it stopped being useful. The hard set has reference answers and tighter keywords.
  • Keywords and the judge disagreed on two questions, which is why I report both and do not pick the favourable one.
  • With 19 questions, a gap this size cannot be separated from noise.

What I would claim, and what I would not

I would claim: the harness runs end to end, treats failed calls safely, and reports "not significant" when that is the answer.

I would not claim: that the fine-tune beats its base, or that these two base models differ. The reference answers and keywords are mine and have not been reviewed by a statistician, and one judge model is one opinion.
