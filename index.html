HOW IT WORKS
1. Drag a battery into the board.
2. Drag a resistor between battery and LED.
3. Drag an LED and connect the chain: + → R → LED → -
4. When the loop closes, the LED lights up and you read the values!
5. Resistors protect the LED. Too many = dim. None = poof.
